# Drawings

The drawings in the docs are generated by three scripts. They use only the Python standard library.

| Script | Makes | From |
|--------|-------|------|
| [`make_panel_svg.py`](make_panel_svg.py) | `panel.svg`, used in the manual, and `panel-plain.svg`, the panel without captions, used on packaging labels | The faceplate KiCad file |
| [`make_assembly_svgs.py`](make_assembly_svgs.py) | `assembly-*.svg`, used in the assembly guide | The main PCB KiCad file |
| [`make_patch_svgs.py`](make_patch_svgs.py) | `patch-*.svg`, the patch examples in the manual | The faceplate KiCad file |

## Panel drawing

The panel drawing in the [user manual](../manual.md) ([`../images/panel.svg`](../images/panel.svg)) is generated from the KiCad faceplate file, [`AttenuverterFaceplate.kicad_pcb`](../../hardware/panel/AttenuverterFaceplate.kicad_pcb).

After changing the faceplate in KiCad, run this from anywhere in the repo:

```sh
python3 docs/drawings/make_panel_svg.py
```

### What it reads

| From the KiCad file | Used for |
|---------------------|----------|
| `Edge.Cuts` lines | Panel outline |
| Mounting-hole footprints and their drill sizes | Jacks (Ø6.0), the knobs (Ø7.0) and the rack screw holes |
| `F.SilkS` lines, arcs and text | The channel outlines, the knob scales and the title |
| `F.SilkS` circles | The black rings around the outputs |
| The logo footprint's `F.SilkS` polygons | The Schenktronics logo |

The script tells holes apart by drill size, so if you change a hole size, update `JACK` and `POT` at the top of the script. The knobs are drawn by the script, and the captions ("In 1", "Knob 1" and so on) are added by the script, not read from KiCad.

## Assembly drawings

After changing the main PCB in KiCad, run:

```sh
python3 docs/drawings/make_assembly_svgs.py
```

| Drawing | How it's made |
|---------|---------------|
| `assembly-1-smd.svg` | Back board view, drawn from the pads, back silkscreen and references in the PCB file. U1's pin 1 and the diodes' cathode pads (pad 1) are marked red. |
| `assembly-2-header.svg` | Back board view with J7's outline. The notch position is the gap in the footprint's outline, set in `fig_header()`. |
| `assembly-3-parts.svg` | Front board view, drawn from the board outline, pads and front silkscreen |
| `assembly-4-faceplate.svg` | Side diagram. The part positions along the board come from the PCB file, and the heights are approximate. |
| `assembly-5-solder.svg` | Back board view, with the pot and jack pads to solder |

The side view assumes the faceplate sits 10 mm further up than the PCB, matching the two KiCad files. If you move the parts on either board, update `OFFSET` near the top of the figures section.

## Patch examples

The patch drawings reuse the panel drawing and add module boxes and cables. Each example is a short function in the script, for example:

```python
def invert_envelope(data):
    p = Patch(data)
    p.source("In 1", "Envelope", "out")
    p.dest("Out 1", "Filter", "cutoff CV in")
    p.turn("Knob 1", -110)
    p.note("Knob 1", "Knob 1 left", "upside-down envelope")
    ...
```

Jacks and knobs are named `In 1`–`In 4`, `Out 1`–`Out 4` and `Knob 1`–`Knob 4`, from the top. Sources go on the left, destinations on the right. `turn()` sets a knob's pointer, in degrees from the center click (negative is anticlockwise). `note()` puts a caption to the left of a knob or jack. Pass `color=BLUE` to draw a second signal. To add an example, write a new function, add it to the list in `main()`, and run:

```sh
python3 docs/drawings/make_patch_svgs.py
```
